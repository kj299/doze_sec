# === REMOTE ACCESS PERSISTENCE ===
# NOTE: ScreenConnect Client, AnyDeskMSI, TeamViewerService,
# RustDeskService, SplashtopStreamer, AteraAgent, KaseyaAgent,
# ConnectWiseControl, BeyondTrustService, level_agent, and fleetdeck
# were removed. These are legitimate service names for commercially-
# licensed RMM/remote-support products used by every MSP-managed
# enterprise endpoint. RMM detection that distinguishes attacker
# from defender requires context (install signature, process tree,
# install date) -- service-name matching alone produces near-100%
# false positives. Section 17's RMM enumeration emits these as
# context lines for an analyst to evaluate.
