# === POWERSHELL OBFUSCATION (T1059.001) ===
# NOTE: Several patterns were removed because findstr substring
# matching produced too many false positives on legitimate PS
# automation:
#   -enc            matched -encoding (Get-Content -Encoding UTF8)
#   iex             native PS alias used in countless signed scripts
#   invoke-expression   used by Chocolatey installer and others
#   downloadstring  used by every PS package bootstrapper
#   downloadfile    same
#   invoke-webrequest   every PS-based update / health-check script
#   new-object net.webclient   used by Microsoft's own Azure scripts
#   reflection.assembly   used by any script doing dynamic types
#   [convert]::     base64/type conversion in many legit scripts
# Retained patterns are stronger signals: -encodedcommand (full
# spelling, less common in legit), specific base64 prefixes (JAB
# starts most PS-encoded payloads), frombase64string, and the
# execution-policy bypass combinations.
-encodedcommand
-e JAB
-e SQBFA
frombase64string
bypass -nop
-nop -w hidden
-exec bypass
