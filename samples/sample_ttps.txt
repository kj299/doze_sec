# Sample TTP feed for doze_sec.bat -importTTP <file>
#
# Format: pipe-delimited rows, one TTP per line, no header
#   MITRE_ID | Name | Detection_Method | Detection_Value | Severity | Actor
#
# Detection_Method must be one of:
#   registry key, event id, process name, file path, named pipe, wmi query
#
# Detection_Value gets sanitized: rows with shell metacharacters
# ("'` $ ; | & < > ( ) { } ^), length 0 or >260, or non-ASCII-printable
# bytes are silently dropped during merge.
#
# Lines starting with # are comments (ignored by the sanitizer because
# they fail the 6-field check, which is harmless).
#
# Usage:
#   doze_sec.bat -importTTP C:\path\to\sample_ttps.txt
#
# After import: rows with method=process name go into ThreatLists\ioc_processes.txt,
# named pipe rows into ioc_named_pipes.txt, and detection commands are
# emitted to %OUTDIR%\ThreatLists\ttp_generated_checks.bat for Section 18
# pickup on subsequent runs.
#
